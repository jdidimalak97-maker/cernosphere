# CERNosphere 🌌

Plateforme web interactive et vitrine du CERN intégrant de l'intelligence artificielle (ML / RAG) et une architecture microservices.

## Architecture & Tech Stack
- **Frontend** : ReactJS + Bootstrap / Tailwind
- **Backend principal** : Laravel 11 (API REST)
- **Microservice IA** : Python 3.12 (FastAPI, scikit-learn)
- **Base de données** : MySQL / PostgreSQL
- **Orchestration** : Docker & Docker Compose
